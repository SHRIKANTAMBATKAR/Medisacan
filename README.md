# Medisacan
🩺 MediScan AI – Image-Based Disease Detection for Remote Areas

MediScan AI is an intelligent healthcare solution that uses deep learning and computer vision to detect multiple diseases from medical images such as skin scans, X-rays, and eye images. It aims to assist healthcare professionals and rural health workers in diagnosing diseases early, even in remote areas with limited access to doctors or diagnostic facilities.

🚀 Key Features

Multi-Disease Detection: Detects various health conditions using CNN-based models.

Image-Based Diagnosis: Accepts medical images (skin, chest X-ray, eye) as input for analysis.

Fast & Accurate Results: Provides real-time predictions with confidence scores.

Remote Accessibility: Designed for use in low-resource or rural healthcare environments.

User-Friendly Interface: Simple web dashboard for uploading images and viewing reports.

🧠 Technology Stack

Frontend: React.js (Responsive UI for doctors and health workers)

Backend: Flask (REST API integration)

Machine Learning: TensorFlow / Keras (CNN Model for image classification)

Dataset: Publicly available medical image datasets for skin, chest X-ray, and eye diseases

Database: MongoDB / Firebase (for storing patient data and diagnosis history)

🏗️ Model Architecture

Convolutional Neural Network (CNN)

Transfer Learning using MobileNetV2 / EfficientNetB0 for high accuracy and low computation

Evaluation Metrics: Accuracy, Precision, Recall, F1-Score, Confusion Matrix

📊 Project Goals

Provide early diagnosis in areas lacking advanced medical infrastructure

Reduce dependency on high-end machines through AI-driven visual analysis

Empower healthcare workers and NGOs with real-time mobile/web tools

📈 Future Enhancements

Add support for more disease categories
